# Business ideas reports

Ranked, research-backed comparisons of candidate business ideas, generated by the
`business-ideas-report` Claude Code skill in `.claude/skills/business-ideas-report/`.

## Generating a report

Open Claude Code in this repo and run one of:

```
/business-ideas-report AI tool that chases unpaid invoices; Marketplace for renting camera gear; Habit tracker for couples
/business-ideas-report docs/business-ideas/ideas.md
/business-ideas-report
```

The third form reads `docs/business-ideas/ideas.md` (one idea per bullet; see
`ideas.example.md`). Copy `ideas.example.md` to `ideas.md` and edit it, or pass any
other file path.

Each run creates `docs/business-ideas/<date>-<slug>/` containing:

| File | What it is |
|---|---|
| `report.md` | The comparison report: ranking, per-idea deep-dive, kill risks, next steps |
| `comparison.md` | The score table on its own |
| `scores.json` | Weighted totals and per-criterion scores, machine-readable |
| `research/<idea>.json` | Raw research per idea, including every source used |

A sample run on the three example ideas is in `2026-09-09-example-batch/`; read its
`report.md` to see what a finished report looks like.

## Founder profile

Fill in `founder-profile.md` once. It feeds the "founder fit and risk" criterion so the
ranking reflects your skills, network and constraints rather than a generic founder.
Until it is filled in, reports assume a solo full-stack developer building on the side.

## How scoring works

Ten criteria scored 1 to 5 against written anchors, each with an evidence grade. The
rubric, weight profiles, gates and anchors are in
`.claude/skills/business-ideas-report/references/scoring-rubric.md`.

- **Weight profiles.** `bootstrap-side` (default), `bootstrap-full-time` and `venture`
  weight the same criteria differently; set yours in `founder-profile.md`. The report
  always shows the ranking under all three.
- **Evidence grades.** A score backed by a survey or a vendor's pricing page counts in
  full; one backed by an estimate or a listicle is pulled towards the midpoint. Ideas rank
  on the adjusted total; the raw total is shown alongside.
- **Gates.** A 1 on problem severity, monetisation, feasibility or timing puts the idea
  below every ungated idea regardless of its total.
- **Comparative scoring.** Researchers propose scores; all ideas are then re-scored
  together, one criterion at a time, so equal scores mean equal things. Every change is
  recorded in the research file.
- **Sensitivity.** The script reports the margin between the top two and whether any
  single one-point change would swap them.

Every idea also carries a confidence label describing how good the evidence was. A
low-confidence idea at the top of the ranking is a prompt for more research, not a
decision. To change the weights or gates, edit `PROFILES` and `GATES` in
`scripts/score_ideas.py` and the matching table in the rubric.
